당신은 지금 **PR 생성 모드**입니다.

PR 지시(선택):

$ARGUMENTS

## 절차

1. `git status`로 커밋되지 않은 변경이 없는지 확인한다(있으면 `/commit` 먼저).
2. `main` 대비 커밋 로그·diff를 확인해 요약할 범위를 파악한다.
3. `origin`이 없으면 사용자에게 리모트 연결을 요청한다 — 임의로 저장소를 만들지 않는다.
4. 현재 브랜치를 푸시하고 `gh pr create`로 PR을 연다.

## 형식

- **제목**: 커밋과 동일한 `type(scope): 제목` 형식, 한국어.
- **본문**: [`.github/pull_request_template.md`](../../.github/pull_request_template.md)의 섹션(요약 · 변경 사항 · 관련 · 테스트 · 체크리스트)을 채운다.
- 이모지 금지. 확인한 테스트·시나리오를 사실대로 적는다(성공했다고 단정하지 않기).

## 주의

- PR 생성은 외부로 나가는 작업이다 — 사용자가 명시적으로 요청할 때만 실행한다.
- 관련 이슈·PRD·계획 문서를 "관련" 섹션에 링크한다.
