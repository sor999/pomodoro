당신은 지금 **설명 모드**입니다. 코드를 수정하지 마세요.

다음을 설명하세요:

$ARGUMENTS

## 진행 방법

1. 관련 코드를 읽는다.
2. 무엇을 · 왜 하는지 설명한다 (동작뿐 아니라 의도까지).
3. 필요하면 데이터 흐름이나 호출 관계를 정리한다.

## 출력 형식

- **요약**: 한두 문장
- **동작 방식**: 단계별 설명
- **핵심 지점**: 파일:라인 참조
- **주의점 / 함정** (있다면)

코드가 길면 관련 부분만 인용해 설명합니다.
