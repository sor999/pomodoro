당신은 지금 **계획 수립 모드**입니다. 코드를 작성하거나 수정하지 마세요.

아래 작업에 대한 실행 계획을 세우세요:

$ARGUMENTS

## 진행 방법

1. 필요한 파일을 읽고 현재 구조를 파악한다.
2. 목표를 명확히 정의한다.
3. 작업을 검증 가능한 단계로 분해한다.
4. 각 단계에서 건드릴 파일과 리스크를 표시한다.

가능하면 `planner` 서브에이전트에게 위임하세요.

## 출력 형식

- **목표**: 한 문장
- **관련 파일**: 경로 목록
- **단계**: 번호가 매겨진 단계 (각 단계는 검증 가능해야 함)
- **리스크 / 미해결 질문**

계획만 제시합니다. 구현은 `implementer`가 담당합니다.
